# Valentine's Card

## What This Is

An interactive web-based Valentine's card to share with a significant other. Features animated hearts, a glitter bomb effect, scattered polaroid photos, Elvis Presley's "Can't Help Falling in Love" playing, and a click-to-reveal personal message. Delivered as a shareable link.

## Core Value

Make them feel loved through a personal, beautiful, interactive experience.

## Context

This is a personal Valentine's Day gift. The card should feel romantic and intimate, not generic. The combination of their photos, a meaningful song, and a personal message makes it uniquely theirs.

The user will provide:
- Photos of them as a couple
- The personal message text

Technical approach should prioritize:
- Visual polish (smooth animations, beautiful design)
- Easy hosting (static site, deployable anywhere)
- Works in modern browsers

## Constraints

- **Tech stack**: Static web (HTML/CSS/JS) — no backend needed
- **Music**: Must handle autoplay restrictions gracefully (click to start)
- **Photos**: User provides their own images
- **Hosting**: Should be deployable to free static hosts (Netlify, Vercel, GitHub Pages)
